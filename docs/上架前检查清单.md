## 一、安全（最关键，务必逐项确认）

- [ ] **删除云函数 `devTools`**
  - 它包含"把自己变成管理员""清空项目/任务""造演示数据"等能力，是最大的安全口子
  - 操作：微信开发者工具 → 云开发控制台 → 云函数 → `devTools` → 删除
  - 现状：已加"开发密钥"闸门（无密钥调用会被拒），但**建议彻底删除**

- [ ] **删除云函数 `devLog`**（临时诊断工具，已停用）
  - 操作同上

- [ ] **三个集合的权限规则**：`users` / `projects` / `tasks` 均设为**自定义安全规则**
  ```json
  { "read": false, "write": false }
  ```
  - 含义：客户端一律不能直接读写，只能通过云函数（服务端会做权限校验）
  - 操作：云开发控制台 → 数据库 → 选中集合 → 权限设置 → 自定义安全规则

- [ ] **云存储权限**：头像目录（`avatars/`）确认只允许登录用户上传、所有用户可读
  - 操作：云开发控制台 → 存储 → 权限设置

- [ ] **确认没有硬编码的密钥遗留在前端代码里**（`lab-progress/` 下不应出现任何 token）

## 三、功能回归（每个角色都要真机过一遍）

### admin（超级管理员）
- [ ] 登录后能看到头像昵称
- [ ] 建项目 → 指定负责人 → 成功
- [ ] 在项目里布置任务 → 指派给成员 → 成功
- [ ] 删除项目 → 提示"同时清理 N 条任务"
- [ ] 成员管理里把某人设为导师/组长，再降回普通成员
- [ ] 进度统计数字与实际一致

### mentor（导师）
- [ ] 能建项目、能指定负责人
- [ ] 能在任意项目里布置任务并指派
- [ ] 能任命组长 / 把组长降回普通成员
- [ ] 不能授予超管（应被拒绝）

### leader（组长）
- [ ] 只能编辑自己负责的项目
- [ ] 只能在自己负责的项目里建/改任务
- [ ] 改别人项目的任务应被拒绝

### member（普通成员）
- [ ] 「我的任务」能看到指派给自己的任务 + 自己负责的项目
- [ ] 能更新**自己任务**的进度与状态
- [ ] 改别人的任务应被拒绝
- [ ] 页面上看不到编辑/删除按钮
